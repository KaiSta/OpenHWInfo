## CPU Infos

`/proc/cpuinfo`

* Name
* Core count
* Clock for each core

lm-sensors `sensors`

* CPU temperature
* PCH temp = chipset

* `-L` GPU name
* Temperature
* Current and max power draw
* RAM current/max
* Utilization
